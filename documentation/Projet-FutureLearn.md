> Version: V1  
> Product type: Corporate / Lead Generation Website

> Secondary language: English  
> Design mode: Clean / Light only  
> Primary conversion: Contact a FutureLearn advisor  
> Primary channel: WhatsApp  
> Secondary channel: Email

---

# 1. PROJECT OVERVIEW

FutureLearn is a Cameroon-based company focused on education, professional development, travel, visa assistance and international mobility.

The website must transform FutureLearn's current service offering into a modern, credible and conversion-oriented digital platform.

The website is not simply an online brochure.

Its primary purpose is to:

1. Explain what FutureLearn does.
2. Help visitors quickly identify the service relevant to them.
3. Build trust.
4. Explain how FutureLearn works.
5. Present destinations and opportunities.
6. Answer common questions.
7. Convert visitors into qualified leads.
8. Make contacting a FutureLearn advisor extremely easy.

The fundamental visitor journey is:

**DISCOVER → UNDERSTAND → TRUST → CHOOSE → CONTACT → CONVERT**

---

# 6. COLOR SYSTEM

Only three primary colors should define the interface:

### Yellow — Primary Brand Accent

Use yellow for:

- primary CTA buttons
- active navigation states
- highlights
- important icons
- numbers
- small decorative elements
- selected states

Yellow must be used carefully.

It should not dominate every component.

### Black — Primary Text / Contrast

Use black or near-black for:

- headings
- primary text
- strong contrast areas
- footer
- important UI elements

### White — Main Background

The website should primarily use white and very light neutral surfaces.

Optional very-light neutral gray tones may be used for:

- backgrounds
- borders
- input fields
- card separation

No blue.

No purple.

No green.

No red as a design accent.

The visual identity must remain:

**YELLOW + WHITE + BLACK**

---

# 7. THEME

# 25. LEAD PROCESSING

After submission:

```text
Visitor
   ↓
Lead Form
   ↓
Validation
   ↓
Server/API
   ↓
Email FutureLearn
   ↓
WhatsApp follow-up
   ↓
Confirmation to visitor
```

Never expose:

- API keys
- SMTP credentials
- private tokens
- service secrets

in client-side code.

Use environment variables and server-side logic.
